# 現勘特助（SiteAide）— 支援與隱私權

App Store 上架用的兩個公開頁面。用 GitHub Pages 發布。

- `index.html` — 支援頁面（App Store Connect 的「支援網址」）
- `privacy.html` — 隱私權政策（App Store Connect 的「隱私權政策網址」；訂閱 App 必填）

## 發布方式

Settings → Pages → Source 選 **Deploy from a branch**，分支 `main`、資料夾 `/ (root)`。

網址會是：

- https://<帳號>.github.io/hyec-app-site/
- https://<帳號>.github.io/hyec-app-site/privacy.html

這個 repo 必須維持 **Public**，而且網址要一直有效——Apple 會定期檢查。
